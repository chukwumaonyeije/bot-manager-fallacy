## 🎯 To Add New Articles

### Quick Steps:

1. **Create file** in `blog/` directory (e.g., `blog/my-new-post.md`)

2. **Use this template:**
```markdown
---
layout: default
title: "🔹 Your Title"
description: "Your description"
author: "Dr. Chukwuma Onyeije"
date: 2025-11-18
keywords:
  - keyword1
  - keyword2
---

![Banner]({{ site.baseurl }}/assets/images/your-banner.png)

[← Back to Blog]({{ site.baseurl }}/blog/)  
[🏠 DoctorsWhoCode Home]({{ site.baseurl }}/)

---

# **Your Title**

*By Dr. Chukwuma Onyeije | Maternal–Fetal Medicine*

---

[Your content here]

---

[← Back to Blog]({{ site.baseurl }}/blog/)  
[🏠 DoctorsWhoCode Home]({{ site.baseurl }}/)
```

3. **Update `blog/index.md`** to add your article to the Featured Articles section

4. **Push to GitHub:**
```bash
git add .
git commit -m "Add new blog post: [Your Title]"
git push origin main
```

5. **Wait 1-2 minutes** for GitHub Pages to rebuild
